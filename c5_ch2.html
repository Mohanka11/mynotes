1. Introduction to Tables

Tables are used to organise and display information in a systematic manner.

Table Structure

Component Description
Column The vertical data is called a column.
Row The horizontal data is called a row.
Cell Each individual rectangle is called a cell. It is a rectangular box that is formed by the intersection of rows and columns.

Table Features

  • Table Move Handle: When you click on a table, a plus sign appears at the top left corner, known as the Table Move handle.
  • Table Resize Handle: A small hollow square at the right corner of the table is called the Table Resize handle.

2. Dynamic Table Creation & Modification

Inserting a Table

  1. Click the Insert tab.
  2. Click Table.
  3. Click Insert Table.
  4. Enter the number of columns and rows.
  5. Click OK.
Note: When you insert a table, two new tabs (Table Design/Design and Layout) appear on the ribbon, displaying various Table tools. In MS Word 2021, the Design tab is renamed as Table Design after inserting a table.

Inserting Rows and Columns

Rows and columns are added using the Layout tab.

  • To add columns: Place the cursor in the table where you want to insert a column. Click the Layout tab, then click Insert Right or Insert Left from the Rows & Columns group.
  • To add rows: Place the cursor in the table where you want to insert a row. Click the Layout tab, then click Insert Above or Insert Below from the Rows & Columns group.
  • Quick Row Insertion: To add a row at the end of a table, click the last cell of the last row, and then press the Tab key.

Deleting Rows and Columns

You can delete rows and columns using the Layout tab.

  1. Place the cursor in the cell of the row/column you want to delete.
  2. Click the Layout tab.
  3. Click the small arrow on Delete from the Rows & Columns group and select Delete Rows or Delete Columns from the menu.
Deleting Content vs. Structure: You can delete the contents of any table without disturbing its structure by selecting the table and pressing the Delete key.

3. Cell Actions & Formatting

Merging vs. Splitting Cells

  • Merging: Combining two or more cells in the same row or column into a single cell is called merging. Many cells can be combined together to create a combined heading. To merge, select the cells, click the Layout tab, and click Merge Cells from the Merge group.
  • Splitting: Breaking up a single cell into multiple cells in a table is called splitting. This is the reverse of the merging process. To split, click the cell, click the Layout tab, click Split Cells from the Merge group, specify the number of columns and rows, and click OK.

Moving and Resizing Tables

  • To move a table: Place the mouse pointer on the Table Move handle until a plus sign appears, drag the table to any part of the document, and release the mouse button.
  • To resize a table: Place the mouse pointer on the Table Resize handle until a double-headed arrow appears, drag the table boundary, and release the mouse button.

Adjusting Row Height and Column Width

Both row height and column width are adjusted using the Layout tab.

  • Row Height: Place the cursor on any cell in the row. Click Layout tab → Properties (from the Table group). In the Table Properties dialog box, click the Row tab, select the Specify height checkbox, use the scroll arrow to adjust, and click OK.
  • Column Width: Place the cursor on any cell in the column. Click Layout tab → Properties. Click the Column tab, select the Preferred width checkbox, use the scroll arrow to adjust, and click OK.

4. Visual Styles & Styling Elements

Borders and Shading

Borders and shading are added using commands from the Borders group.

  • Adding Borders: Select the cells and click the Design tab. Click Borders → Borders and Shading option. Choose the style, color, and width of the border in the dialog box, and click OK.
  • Adding Shading: Select the cells and click the Design tab. Click Shading from the Table Styles group and click the color of your choice from the drop-down menu.

Table Styles

  • Table Styles is an inbuilt facility of Microsoft Word for changing the look, colour, and design of the borders of a table.
  • It is present in the Design tab on the ribbon, which appears only when a table is inserted.
  • Steps: Click the table, click the Design tab, click the More button in the Table Styles group, and choose any visual style from the gallery.

5. Advanced Table Actions

Converting Text to Table

Microsoft Word provides the option of converting text into tables and vice-versa.

  • Steps: Select the already typed text, click the Insert tab, click Table from the Tables group, and select Convert Text to Table. Enter the number of columns in the Table size section, select an option from the Separate text at section, and click OK.

Inserting Pictures in a Table

  • Steps: Click the desired cell, click the Insert tab, select the Pictures option from the Illustrations group, select the picture to be inserted, and click the Insert button.
