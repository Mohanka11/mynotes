CSS Properties Study Guide

Inline Styling, Text Formatting, Typography, Box Margins & Borders

1 Introduction & Inline CSS Style

  • Purpose of CSS: Used to control the presentation, styling, and visual layout of HTML elements on a web page.
  • Inline CSS: Applied directly to an individual HTML tag using the style attribute (e.g., <p style="color: blue;">).
Disadvantages of Inline CSS:
  • It only impacts the specific tag where it is defined, making it unsuitable for site-wide styling.
  • Lacks reusability; styles must be manually duplicated across every element, complicating code maintenance.

2 Text Properties

Text decoration and formatting properties control the alignment, color, and spacing of content:

text-align

Horizontally aligns text relative to parent container margins (left, right, center, justify).

text-decoration

Applies or removes decorative line styling (overline, line-through, underline, none).

color

Sets the text color using standard color keywords, Hex codes (e.g., #ff0000), or RGB notation.

text-transform

Modifies capitalization casing across text (capitalize, uppercase, lowercase, none).

text-shadow

Adds drop shadows using horizontal offset (h-shadow), vertical offset (v-shadow), and color. Multiple shadows can be separated by commas.

text-indent

Indents the first line of a paragraph using specific lengths (pixels) or percentage values.

line-height

Adjusts vertical spacing between lines of text (supports numbers, length units, percentages, or normal).

word-break

Specifies line breaking rules for handling word wrapping on narrow display boundaries.

3 Font Properties

  • Font Family (font-family): Declares a prioritized list of specific typefaces (e.g., Arial, Times New Roman) and fallback generic families (e.g., sans-serif).
  • Font Size (font-size): Sets font scale using absolute or relative units such as pixels (px), percentage (%), points (pt), or em.
  • Font Style (font-style): Specifies typeface slant using normal, italic, or oblique.
  • Font Shorthand (font): Combines font-style, font-size, and font-family into a single compact declaration.

4 Margin Properties

  • Purpose: Clears an area around elements outside the border to control layout spacing.
  • Directions: Can be declared independently per side using margin-top, margin-right, margin-bottom, and margin-left.
  • Accepted Values: Supports browser-calculated auto, absolute lengths (px, cm, pt), relative percentages (%), as well as negative values for overlapping layouts.

5 Border Properties

border-width

Configures border thickness via standard units (px, pt, cm) or keywords (thin, medium, thick).

border-style

Sets visual border pattern (solid, dashed, dotted, double, groove, ridge, inset, outset, none, hidden).

border-color

Sets border colors using keywords, Hex, or RGB. Supports 1–4 side values; defaults to inheriting the parent element's text color if omitted.

border (Shorthand)

Specifies border-width, border-style, and border-color simultaneously in one line (e.g., border: 2px solid #333;).
