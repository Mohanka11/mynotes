Internet & Cybersecurity Guide

Viruses, Threats, Ethics, Safety Practices & Digital Footprints

1 Introduction to the Internet

  • Definition: A worldwide network of computers that connects computing systems globally.
  • Most Common Service: The World Wide Web (WWW or Web), hosting websites, blogs, and vast resources across virtually every topic.
  • Access & Risk: Web pages are publicly accessible unless password-protected or restricted. However, online data is not always reliable and can host malicious computer viruses.

2 Computer Viruses

Full Form: VIRUS stands for Vital Information Resources Under Seize.
  • Definition: A computer program deliberately engineered by creators to replicate itself across different storage areas or infect remote machines automatically.
  • Nature: Not all harmful programs are viruses, and not all viruses cause destructive damage (the majority are designed merely to irritate users).
  • Hardware Safety: Viruses target software and data; they do not physically damage hardware components such as keyboards or monitors.

3 Harm & Symptoms of Infection

Harm Caused: Consuming storage via infinite replication, file corruption, permanent data deletion, and transmitting stolen passwords or banking details over the web.

Key Symptoms of an Infected System:

  • Frequent system freezes, lockups, and degraded performance.
  • Unusual screen distortions or visual glitches.
  • Unexplained data loss or missing files.
  • Unexpected system error dialogs and pop-up messages.

4 How a Computer Gets Infected

  • Connecting and opening files from infected external media (CDs, pen drives).
  • Opening malicious email attachments.
  • Visiting untrusted websites and downloading infected executables.
  • Launching an infected software application, which subsequently spreads into memory and infects other programs.

5 History of Computer Viruses

1982 — Elk Cloner

Created by Rich Skrenta; attached to Apple DOS 3.3 and spread via floppy disks. Originally conceived as a high-school prank that displayed a poem on the 50th boot.

1986 — Brain

Developed by Pakistani brothers Basit and A. F. Alvi as the first PC boot sector virus, intended to prevent unauthorized copying of their software.

Mid-1990s — Macro Viruses

Emerged using embedded scripting languages inside productivity files like Microsoft Word and Excel.

Modern Era — Network Distribution

Emails, instant messaging channels, and chat applications became the primary global delivery vectors.

6 Types of Computer Viruses

Bombs e.g., Logic Bomb

Designed to remain dormant until triggered by a specific event or date to execute payload damage.

Boot Sector Viruses e.g., Elk Cloner, Brain

Targets the master boot record/sector of the disk containing critical system startup instructions.

E-Mail Viruses e.g., Gift Card Scam

Distributes via malicious attachments and replicates to the hard disk upon opening.

Trojans e.g., Bit Frost

Disguised as legitimate software to deceive users into execution, then steals sensitive data.

Worms e.g., Blaster, Morris

Self-replicating standalone programs that consume network bandwidth and drive space without host files.

Browser Hijackers e.g., CWS

Modifies browser configuration settings to forcibly redirect user queries to unwanted or infected domains.

Web Scripting Viruses e.g., DDoS targets

Breaches web application security to inject malicious scripts or automate unauthorized activities on websites.

Polymorphic Viruses e.g., VIRLOCK, BAGLE

Modifies its binary signature each replication cycle to evade traditional signature-based antivirus scanners.

7 Protecting Your Computer

  • Avoid using removable storage devices (pen drives, CDs) from unknown sources without scanning.
  • Download software and resources exclusively from verified, reputable repositories.
  • Never download or open email attachments from unknown or unverified senders.
  • Maintain active antivirus protection with up-to-date virus definition databases.
  • Immediately exit websites that initiate unauthorized URL redirects.

8 Unethical Practices on the Internet

  • Plagiarism: Presenting another person's creative work, text, or ideas as your own without authorization or proper attribution.
    Prevention: Cite references accurately, secure written permissions, and quote source material directly.
  • Cyberbullying: Harassing, intimidating, or demeaning individuals using digital communication tools.
    Prevention: Restrict visibility of personal media, set profiles to private, use strong authentication, and pause before posting.
  • Cyberstalking: Persistent online tracking, monitoring, or intimidation intended to cause distress (often encompasses cyberbullying and identity theft).
  • Hacking: Gaining unauthorized access to remote systems to manipulate data or control computing resources.
    Prevention: Patch software vulnerabilities, avoid pirated programs, update antivirus tools, and enforce unique passwords.
  • Phishing: Deceptive emails masquerading as trusted institutions (like banks) to harvest credentials and financial info.
    Prevention: Disregard unsolicited verification requests, verify senders, and never click embedded authentication links.
  • Spamming & Mail Bombing: Flooding inboxes with unwanted promotional bulk messages (spam) or overloading mail server storage capacities with automated mass emails (mail bombing).
    Prevention: Utilize strict email spam filters and avoid publishing primary email addresses publicly.

9 Best Practice Safety Measures

  • Antivirus & Scans: Configure security suites to run automated, scheduled disk integrity scans.
  • Password Strength: Combine uppercase, lowercase, numbers, and special symbols; rotate passwords on a regular basis.
  • Data Backups: Maintain regular redundant copies of essential files across independent drives or cloud storage.
  • Access Controls: Never leave active workstations unattended or unlocked in shared or public spaces.
  • Safe Disposal: Securely sanitize, overwrite, or destroy all storage drives prior to selling or recycling old computers.
  • Network Firewall: Enable hardware or software firewalls to inspect and filter untrusted incoming internet traffic.

10 Digital Footprints

Definition: The persistent trail of data and online transaction logs left by users across the web (also called a digital dossier).

Passive Footprint

Data gathered without active user awareness (e.g., web server logs recording IP addresses, geographic location, and device details).

Active Footprint

Data shared deliberately by the user (e.g., submitting online registrations, publishing posts, or uploading multimedia).

Best Safeguards:

  • Engage private browsing modes to limit tracking cookies.
  • Refrain from sharing sensitive personal records on unencrypted or untrusted websites.
  • Audit social media posts and media uploads for personally identifiable metadata.
