1. Selecting and Deselecting Cells or Ranges

Navigating and selecting cell ranges accurately is essential for editing, formatting, and applying formulas efficiently in Microsoft Excel.

Selection Techniques

  • Keyboard Selection: Press Shift + Arrow keys to expand the selection to adjacent cells.
  • Entire Row or Column: Click the column heading to select a full column, or click the row heading to select a full row.
  • Entire Worksheet: Click the cross-section box between the row and column headers, or press Ctrl + A.
  • Extend Selection Mode (Large Ranges): Click the starting cell, press F8 to enable Extend Selection mode (indicated on the Status bar), click the ending cell, and press F8 again to turn it off.
  • Non-Adjacent Ranges: Select the first range, hold down the Ctrl key, and select additional ranges.

Selection Shortcuts

Shortcut Key Action / Result
Shift + Spacebar Selects the active row.
Ctrl + Spacebar Selects the active column.
Ctrl + A Selects the entire worksheet.
Tip: Hold down the Ctrl key when you need to select multiple separate cells or blocks of data across the worksheet.

2. Entering Numbers as Text, Dates, and Times

Understanding how Excel interprets numbers, text, dates, and times prevents data formatting errors and unexpected loss of information.

Numbers as Text

Standard numbers automatically align to the right side of a cell. To preserve leading zeros (e.g., telephone codes or ID numbers like 07286), type an apostrophe (') before the number (e.g., '07286). This converts the entry to text and aligns it to the left.

Steps to Format Numbers, Dates, and Times

  1. Select the target cells.
  2. Go to the Home tab → click the Format command (in the Cells group) → select Format Cells (or right-click and choose Format Cells).
  3. Under the Number tab, pick a category (e.g., Number, Date, or Time).
  4. Select the desired display format from the list.
  5. Click OK.
An apostrophe (') tells Excel to treat numeric entries strictly as text, making sure leading zeros are not automatically deleted.

3. Basic Operations on Cells, Rows, and Columns

Excel provides straightforward tools to edit, move, insert, and delete structural elements without losing data integrity.

Editing, Copying, and Moving

  • Editing: Modify cell contents directly by double-clicking the cell or over-writing existing data.
  • Copying Cell Contents: Select cell → Home tab → Copy (or press Ctrl + C) → choose target cell → Paste (or press Ctrl + V).
  • Moving Cell Contents: Select cell → Home tab → Cut (or press Ctrl + X) → choose target cell → Paste (or press Ctrl + V).

Inserting and Deleting Cells, Rows, and Columns

Operation Navigation Path Options / Action
Insert Cells Home tab → Insert drop-down → Insert Cells Select Shift cells right or Shift cells down → click OK.
Delete Cells Home tab → Delete drop-down → Delete Cells Select the shift direction → click OK.
Insert Rows/Columns Home tab → Insert drop-down Select Insert Sheet Rows or Insert Sheet Columns.
Delete Rows/Columns Home tab → Delete drop-down Select Delete Sheet Rows or Delete Sheet Columns.

4. Formatting Numbers and Borders

Formatting improves visual layout, making data easier to review and present in clean table structures.

Quick Formatting Controls

  • Number Group: Use the quick controls in the Number group under the Home tab to apply currency symbols, percentages, decimals, and comma styles quickly.
  • Applying Borders:
    1. Select the target cells.
    2. Click the Borders drop-down menu on the Home tab (Font group).
    3. Select the desired border style (e.g., All Borders, Outside Borders, or Thick Box Border).
Applying grid borders manually ensures that table lines remain bold and clearly defined when printing or exporting worksheets.

5. Auto Fill Feature

The Auto Fill feature automatically generates a predefined sequence of data (such as numbers, dates, weekdays, or months) to save manual typing effort.

Types of Sequences

  • Numeric Series: Type the first two values to establish the increment pattern, select both cells, and drag the Fill handle (the small square at the bottom-right corner) over the target range.
  • Predefined Lists: Type the initial entry (e.g., Sunday or January) and drag the Fill handle across adjacent cells.
Remember: For a custom numeric series (e.g., 2, 4, 6, 8...), you must type at least two numbers so Excel can detect the step interval.

6. Flash Fill Feature

Flash Fill automatically recognizes patterns in adjacent data columns and instantly completes remaining entries without requiring complex formulas.

Steps to Use Flash Fill

  1. Enter a sample pattern manually in a column next to your data.
  2. Press Enter to move to the next row.
  3. Navigate to the Home tab → Editing group → Fill drop-down menu.
  4. Click Flash Fill (or press shortcut Ctrl + E).
Flash Fill is ideal for combining names (First + Last), extracting domain names from email addresses, or reformatting phone numbers without using string formulas.
