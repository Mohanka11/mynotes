2. Conditional Formatting

Conditional Formatting automatically changes the appearance of cells based on specified conditions. It helps identify important values quickly.

Example

Highlight student marks greater than 250 using a green fill.

Steps to Apply Conditional Formatting

  1. Select the required cell range.
  2. Click the Home tab.
  3. Select Conditional Formatting from the Styles group.
  4. Choose the desired rule (e.g. Highlight Cells Rules → Greater Than).
  5. Enter the value and choose the formatting style.
  6. Click OK.
Conditional Formatting makes worksheets easier to read by automatically highlighting important information.

3. Sorting Data

Sorting arranges worksheet data in a meaningful order.

Sorting Type Description
Ascending Arranges data from A–Z or smallest to largest.
Descending Arranges data from Z–A or largest to smallest.
Multi-Level Sorting Sorts data using more than one column.

Steps for Multi-Level Sorting

  1. Select the complete data range.
  2. Open the Data tab.
  3. Click Sort.
  4. Click Add Level.
  5. Specify another column in the Then By section.
  6. Click OK.
Use Multi-Level Sorting when two or more columns need to be sorted together.

4. Filtering Data

Filtering displays only the records that satisfy selected conditions while hiding the remaining rows.

Steps to Apply Filter

  1. Select any cell in the data range.
  2. Click the Data tab.
  3. Select Filter.
  4. Click the filter arrow of the required column.
  5. Select or deselect values.
  6. Click OK.

Custom Filter

Custom Filters allow two conditions to be applied together using AND or OR operators.

Example: Display Maths marks greater than or equal to 80 AND less than 90.

5. Grouping Worksheets

Grouping Worksheets lets you edit multiple worksheets at the same time.

How to Group Worksheets

  • Non-Consecutive Sheets: Hold the Ctrl key and select required sheet tabs.
  • Consecutive Sheets: Hold the Shift key and click the first and last worksheet tabs.
  • Grouped worksheets display (Group) in the title bar.

Ungroup Worksheets

  • Click any sheet outside the group.
  • Or right-click a grouped sheet tab and choose Ungroup Sheets.
Changes made to one grouped worksheet are automatically applied to all grouped worksheets.

6. Consolidating Data

Data Consolidation combines information from multiple worksheets into one master worksheet.

Steps

  1. Create worksheets such as Theory Marks, Practical Marks and Total Marks.
  2. Enter data into the source worksheets.
  3. Open the Total Marks worksheet.
  4. Select the destination cell.
  5. Click Data → Consolidate.
  6. Select the SUM function.
  7. Add references from each worksheet.
  8. Click OK.
Consolidation helps summarize information from several worksheets into a single report.
