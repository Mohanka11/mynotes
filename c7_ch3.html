1. Introduction to Charts

Numeric Data: Presenting data and information in the form of numbers.

Chart / Graph: A pictorial representation of numeric data.

Advantages of Charts

  • Present data and information in an attractive and compact manner.
  • Are easier to understand and compare.
  • Have a long-lasting effect on the mind compared to a simple data statement.

2. Components of a Chart

Component Description
Plot Area A rectangular area bounded by two axes where the chart is plotted.
Y-Axis / Value Axis The vertical axis of the chart.
X-Axis / Category Axis The horizontal axis of the chart.
Data Points Bars, lines, slices, or other elements that represent the data value.
Chart Area The area containing all objects of the chart.
Legend Identifies each data series with a unique color or pattern.

3. Types of Charts in Microsoft Excel 2016

Chart Type Description & Key Characteristics
Column Chart Shows data changes over a period of time or illustrates comparisons among items.
Line Chart Shows different trends in data at equal intervals using varying line styles.
Pie Chart A circular chart divided into parts that shows only one data series, representing the contribution of each part to the total.
Bar Chart Shows comparisons among individual items.
Area Chart Shows the trend of values over a period of time or categories.
Doughnut Chart Displays data in rings where each ring represents a data series (includes subtypes like Exploded Doughnut).

4. Creating Charts

Location: Charts can be created in the current worksheet or as an object in a separate worksheet in the current workbook.

Creation Methods

  • Method 1 (Manual): Select cells → Click Insert tab → Select chart type → Select chart subtype.
  • Method 2 (Shortcut): Select cells and press the F11 key. Excel automatically creates a chart on a new chart tab (this is the shortest and easiest way to create a chart).
Chart Tools:
Upon creation, the Chart Design / Design tab and Format tab appear on the ribbon to display various chart tools.

5. Formatting and Customizing Charts

Chart Design Tab: Used to change the chart type, modify source data, add more data, or change the chart location.

Customization Steps

  1. Changing Chart Type: Select chart → Click Change Chart Type in the Type group → Choose new type/subtype → Click OK.
  2. Changing Chart Style: Select chart → Click the More button in the Chart Styles group → Click desired style.
  3. Changing Chart Options: Select chart → Click Chart Design tab → Select Add Chart Element in the Chart Layouts group to add options like Chart Title, Axis Title, Legend, Data Labels, Axes, and Grid lines.

6. Resizing, Moving, and Deleting Charts

  • Resizing: Adjust a chart by dragging its corner frames (handles) diagonally for proportional resizing.
  • Moving: Click anywhere on the chart and drag it in the desired direction.
  • Deleting: Click anywhere on the chart to select it and press the Delete key.
Data Linking:
Chart data and text are linked to the worksheet. Changing or deleting data/text in the worksheet automatically updates or deletes those elements in the chart.

7. Sparkline Charts

Definition: A tiny chart embedded into a single cell in the worksheet to show and analyze data trends.

Insertion Steps

  1. Select row/rows cells.
  2. Click the Insert tab.
  3. Select Sparkline type.
  4. Type range in the Location Range box.
  5. Click OK.

Types of Sparklines

  • Line: Shows trends in data at equal intervals.
  • Column: Shows data changes over time or illustrates comparisons.
  • Win/Loss: Shows if a cell value is positive (win), negative (loss), or zero (tie).
Customization:
Change Sparkline Type or Style via the ribbon's Sparkline tab.

8. Combo Charts

Definition: A combination of two or more chart types in a single chart to represent and compare interrelated sets of values.

Creation Steps

  1. Select cell range.
  2. Click Insert Combo Chart in the Insert tab.
  3. Select Create Custom Combo Chart.
  4. Choose chart types (e.g., Clustered Column for series 1, Line with Markers for series 2).
  5. Click the Secondary Axis checkbox for one series.
  6. Click OK.

9. Printing Charts

  1. Select the chart.
  2. Click the File tab.
  3. Click the Print option.
  4. Click the Print button.
