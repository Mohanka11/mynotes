1. Understanding Formulas

Definition: Formulas are equations used to perform calculations on worksheet values.

Start Character: Every formula must begin with an equal sign (=). If a space is given before =, Excel treats the cell content as text rather than a formula.

Components: Can consist of constants, numbers, cell addresses/references, names, cell ranges, operators, or built-in library functions.

Key Point:
Always ensure no spaces precede the = sign so that Excel evaluates the expression as a formula instead of plain text.

2. Types of Formulas

Formula Type Description Example
Basic Formula Contains only one type of operator (such as only addition +). =A1+A2+A3
Compound Formula Used when more than one operator is required to perform calculations. =B3*B4*B5/100
Cell Ranges Groups of continuous cells used in a formula to save time. =SUM(B3:B8)
Text Formula (Concatenation) Simple text values enclosed in double quotes joined using the ampersand (&) operator. "Microsoft" & "Excel" → Microsoft Excel

3. Types of Cell Referencing

Referencing Type Syntax / Format Description
Relative Referencing
(Default)		 A1 Cell references change automatically according to the position where the formula is copied. Neither the column nor row parts are fixed.
Absolute Referencing $B$3 Both the column and row are fixed with a dollar sign ($). The reference remains unchanged when the formula is copied to other cells.
Mixed Referencing $B3 or C$3 Only one part of the cell address (either column or row) is fixed with a $ sign.
Referencing Another Worksheet Sheet1!D7 To reference a cell in another sheet, use the worksheet name followed by an exclamation mark (!) and the cell address.

4. Excel Functions

Functions are predefined commands that act on a cell or range of cells to perform operations quickly. They consist of the function name and arguments inside round brackets, always beginning with an = sign.

Math & Trig Functions

  • INT: Rounds a number down to the nearest integer.
  • LCM: Returns the least common multiple of a range of numbers.
  • MOD: Returns the remainder after division.
  • POWER: Raises a number to a specified power.
  • PRODUCT: Multiplies numbers in a given range.
  • QUOTIENT: Returns the integer quotient of a division.
  • ROUND: Rounds a number to a specified number of decimal digits.
  • SQRT: Returns the square root of a number.

Statistical Functions

  • SUM: Adds all numbers in a given range.
  • AVERAGE: Calculates the mean of a range of numbers.
  • COUNT: Counts cells containing numeric values.
  • MAX / MIN: Displays the largest or smallest value in a range.

Text, Date & Logical Functions

  • LEN (Text): Counts the number of characters in a text string.
  • TODAY (Date & Time): Displays the current date.
  • IF (Logical): Evaluates a condition and returns one value if TRUE, and another if FALSE.
    Syntax: =IF(condition, value_if_True, value_if_False)

5. The Function Wizard

The Insert Function command (fx button) is located in the Function Library group on the Formulas tab of the ribbon.

How it helps:
It helps users search for functions by typing a description or choosing a category (such as Math & Trig, Statistical, etc.) to easily configure parameters using a step-by-step dialog box.
