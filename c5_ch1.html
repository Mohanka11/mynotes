1. The Dawn of Computing

The history of computing began with simple calculating devices and gradually developed into advanced mechanical machines that laid the foundation for modern computers.

Device Developer Technology Features
Abacus China (3000 BCE) Wooden Frame & Beads First calculating device for addition, subtraction, multiplication and division.
Napier's Bones John Napier (1617) Numbered Rods Performed multiplication and division.
Pascaline Blaise Pascal (1642) Gears & Wheels Adding machine for addition and subtraction.
Difference Engine Charles Babbage (1822) Mechanical Calculator Produced mathematical tables automatically.
Analytical Engine Charles Babbage (1837) Automatic Digital Computer Design Included Input, Output, Store, Mill and Control Unit.
Key Point:
The Analytical Engine is considered the blueprint of the modern computer because it introduced the concepts of CPU, Memory and Program Control.

2. Five Generations of Computer Evolution

First Generation (1946–1959)

  • Vacuum Tubes
  • Very large and expensive
  • Generated excessive heat
  • Examples: ENIAC, EDVAC, UNIVAC

Second Generation (1959–1965)

  • Transistors
  • Smaller, faster and reliable
  • Less heat generation
  • Examples: IBM 1401, IBM 700, CDC 160

Third Generation (1965–1971)

  • Integrated Circuits (ICs)
  • Smaller and more accurate
  • High processing speed
  • Examples: IBM 360, ICL 1900, VAX-750

Fourth Generation (1971–1980)

  • Microprocessors
  • Portable computers
  • Affordable and powerful
  • Examples: IBM 4300, ICL 2900, HP 9000

Fifth Generation (1980–Present)

  • Artificial Intelligence
  • Robotics
  • Machine Learning
  • Expert Systems
Remember: Computers evolved from Vacuum Tubes → Transistors → ICs → Microprocessors → Artificial Intelligence.

3. Windows 10 - Managing Live Tiles

Live Tiles display updated information such as Weather, Mail and News directly on the Start Menu.

Pin an App

  1. Locate the application.
  2. Right-click it.
  3. Select Pin to Start.

Resize a Tile

  1. Right-click the tile.
  2. Click Resize.
  3. Select Small, Medium, Wide or Large.

Group Tiles

  • Drag a tile to the bottom.
  • Name the group.
  • Move the group using the two lines.

Turn Live Tile Off

  1. Right-click Tile.
  2. More
  3. Turn Live Tile Off

4. Universal Apps & Desktop Personalization

Universal Apps

Universal Apps work on desktops, laptops and smartphones.

  • Photos
  • Mail
  • Weather

Change Desktop Color

  1. Right-click Desktop.
  2. Choose Personalize.
  3. Select Colors.
  4. Choose Accent Color.
  5. Enable Start, Taskbar and Action Center.
  6. Enable Title Bars and Window Borders.
Windows 10 provides an easy-to-use interface with customization features that improve productivity and user experience.
