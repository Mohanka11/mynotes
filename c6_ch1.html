1. Introduction to Computers

A computer is an electronic device that accepts raw data as input, processes it according to stored instructions, and produces meaningful information as output[cite: 1].

Core Functional Cycle (IPO)

  • Input: Receiving raw data and instructions entered by the user[cite: 1].
  • Process: Performing arithmetic and logical operations on the data based on given instructions[cite: 1].
  • Output: Delivering the processed data (information) to the user via display screens, printers, or storage devices[cite: 1].
Key Takeaway: The fundamental operation of any computing device rests on processing input instructions accurately to generate the desired output[cite: 1].

2. Categories of Computers

Computers are broadly classified based on their size, processing power, data handling capabilities, and intended operational environment[cite: 1].

Primary Classification

  • Microcomputers: Small, low-cost personal computers powered by single-chip microprocessors designed for individual use (e.g., Commodore 64, IBM PC, desktop PCs, laptops)[cite: 1].
  • Minicomputers: Medium-sized multi-user systems offering greater processing power and memory capacity than microcomputers, supporting multiple simultaneous users (e.g., VAX, PDP-8)[cite: 1].
  • Mainframe Computers: High-performance multi-CPU systems engineered for massive data storage, high-speed input/output throughput, and multi-user transaction processing across large enterprises (e.g., IBM System/390)[cite: 1].
  • Supercomputers: The world's fastest systems, utilizing parallel arrays of thousands of CPUs and GPUs to carry out complex numerical computations and simulations (e.g., Frontier, Summit)[cite: 1].

Summary of Categories

Category Primary Architecture Key Use Cases Examples
Microcomputer Single-chip microprocessor Personal productivity, education, office work Commodore 64, IBM PC[cite: 1]
Minicomputer Multi-user mid-range processors Departmental data handling, manufacturing control VAX, PDP-8[cite: 1]
Mainframe Multi-CPU, high I/O bandwidth Banking systems, census data, enterprise ERP IBM 390[cite: 1]
Supercomputer Massive parallel CPU/GPU clusters Weather forecasting, nuclear physics, molecular modeling Frontier[cite: 1]

3. Specialized Computing Devices

Beyond general-purpose computers, dedicated computing architectures are engineered to optimize specific tasks, environments, or entertainment applications[cite: 1].

Types of Dedicated Devices

  • Game Consoles: Dedicated hardware designed primarily for running high-end interactive video games without requiring standard computer peripherals like keyboards or general desktop monitors (e.g., Microsoft Xbox, Sony PlayStation)[cite: 1].
  • Embedded Computers: Compact, specialized microcontrollers built directly into larger mechanical or electrical systems to control a single, dedicated function (e.g., GPS Receivers, Amazon Kindle, Digital Glucometers, automotive engine controls)[cite: 1].
Embedded Systems: Embedded computers run specialized, hardcoded firmware rather than general operating systems, making them highly efficient and resilient for their specific tasks[cite: 1].

4. Evolution of Computer Languages

Computer languages have evolved from hardware-dependent binary notations to high-level, human-readable abstractions and AI-driven declarative formats[cite: 1].

1. Low-Level Languages (LLL)

  • First Generation (1GL - Machine Language): The native language of computers consisting entirely of binary digits (0s and 1s)[cite: 1]. It requires no translation but is hardware-dependent and difficult to write or debug[cite: 1].
  • Second Generation (2GL - Assembly Language): Uses mnemonic codes (such as ADD, SUB, MOV) in place of binary strings[cite: 1]. It remains machine-dependent and requires an Assembler to convert instructions into machine code[cite: 1].

2. High-Level Languages (HLL)

  • Third Generation (3GL): Utilizes English-like keywords, statements, and mathematical notation (e.g., C, C++, Java, Python)[cite: 1]. These languages are portable across multiple hardware architectures[cite: 1].
  • Fourth Generation (4GL): Non-procedural, specialized query and reporting languages designed to specify what to do rather than how to do it, significantly reducing code complexity (e.g., SQL)[cite: 1].
  • Fifth Generation (5GL): Languages centered on artificial intelligence, problem-solving through constraints, and natural language processing (e.g., Prolog, Mercury)[cite: 1].

5. Program Translators

Computers can only execute binary machine code directly[cite: 1]. Language translators bridge the gap between human-written source code and machine-executable binary[cite: 1].

Types of Translators

Translator Source Input Translation Method Output & Execution
Assembler Assembly Language (2GL)[cite: 1] Translates mnemonic instructions directly into object code[cite: 1]. Generates machine-readable binary code[cite: 1].
Compiler High-Level Language (3GL/4GL)[cite: 1] Scans and translates the entire source program at once[cite: 1]. Produces an independent object/executable file; execution is fast after compilation[cite: 1].
Interpreter High-Level Language (3GL/4GL)[cite: 1] Translates and executes source code line by line[cite: 1]. Does not create a separate object file; stops immediately upon encountering an error[cite: 1].
Key Difference: A Compiler converts the entire code into machine language before execution, whereas an Interpreter translates code line-by-line during runtime[cite: 1].
