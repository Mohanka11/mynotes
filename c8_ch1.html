1. Introduction to Computer Networks

A network is a group of devices connected together to allow the seamless exchange of data and information.

Key Concepts

  • Computer Network: A collection of computers and peripheral devices (such as printers and scanners) linked by communication channels.
  • Networking: The method and process of connecting computing devices together to share resources.
  • Workstation: An individual personal computer connected to a network.
  • File Server: A central, powerful computer that manages, stores, and distributes files, software applications, and programs to connected network users.

2. Components of Data Communication

Every data transmission across a network requires five fundamental elements to communicate successfully:

Component Description / Role Example
1. Message The actual information or payload being transmitted. Text, audio clips, video files, or images
2. Sender The source device that originates and dispatches the data. Computer, laptop, or smartphone
3. Receiver The destination device intended to receive the message. Computer, printer, or mobile device
4. Communication Medium The physical transmission path through which signals travel. Cables (twisted pair, fiber) or radio waves
5. Protocol The strict set of rules governing data transmission. TCP/IP, HTTP, FTP

3. Benefits of a Network

Establishing a computer network provides several operational and economic advantages:

  • Ease of Access: Information stored on a centralized server is organized and accessible from any authorized terminal.
  • Work From Home: Remote users can securely access workplace network resources using communication devices and modems.
  • Hardware Resource Sharing: Cost reduction achieved by sharing expensive hardware peripherals like laser printers, storage drives, and scanners.
  • Software & Program Sharing: Software only needs to be installed and updated once on the central server, boosting administrative efficiency.
  • Centralized Security: Access control mechanisms using unique usernames and passwords restrict sensitive data to authorized personnel.

4. Networking Media (How Data Travels)

Data signals travel from one network node to another via physical wires or atmospheric waves.

1. Wired Media (Guided / Transmission Media)

  • Uses physical cabling to transmit signals; cable quality directly affects bandwidth and speed.
  • Twisted Pair Cable: Common copper wires twisted in pairs to reduce interference; standard for Ethernet LANs.
  • Coaxial Cable: Insulated copper cable with metallic shield; widely used in cable television systems.
  • Optical Fibre Cable: Transmits light pulses through thin glass strands; offers the highest data transfer speeds over long distances.

2. Wireless Media (Unguided Media)

  • Transmits electromagnetic signals through the air without physical conductors.
  • Bluetooth: Short-range wireless connectivity for personal peripherals.
  • Infrared: Line-of-sight communication typically used in device remote controls.
  • Wi-Fi (Wireless Fidelity): Radio-wave based standard for local wireless networking.

5. Types of Networks by Scale

Networks are classified by their geographic coverage area:

Network Type Full Name Geographical Coverage Typical Use Case
PAN Personal Area Network Within a few meters (under 10 m) Connecting phone to laptop or wireless earphones
LAN Local Area Network Single room, office, or building School computer lab or office building
CAN Campus Area Network Across multiple nearby buildings College campus, school complex, or military base
MAN Metropolitan Area Network Across an entire city or town City cable TV network, municipal branches
WAN Wide Area Network Countrywide, continental, or global The Internet, multinational banking networks

6. Network Topology (Arrangement of Computers)

Topology refers to the geometric arrangement and interconnection pattern of computers (nodes) on a network.

Comparison of Major Topologies

Topology Layout / Structure Key Advantage Key Disadvantage
Star Topology All nodes connect directly to a central device (switch/hub). Easy to install; single node failure doesn't stop the network. If the central switch fails, the whole network goes down.
Ring Topology Nodes connected in a closed ring; data flows in one direction. Orderly data flow without packet collisions. A breakdown in any single node breaks the entire network loop.
Bus Topology All nodes connect to a single central backbone cable (bus). Low cable requirement and cost-effective setup. A break in the central backbone cable halts all communication.
Mesh Topology Every single node has a dedicated link to every other node. Extremely fast, robust, and reliable (no single point of failure). Most expensive and complex to cable and maintain.

7. Important Networking Devices

  • MODEM (Modulator-Demodulator): Converts digital signals from a computer into analog signals for telephone lines, and converts incoming analog signals back to digital.
  • Hub: A multiport hardware device that broadcasts incoming data packets indiscriminately to all connected devices.
  • Switch: An intelligent networking device that inspects data packets and directs them only to the intended destination node.
  • Router: Connects separate networks (e.g., a home LAN to the ISP) and calculates the shortest, optimal path for data packets.
  • Gateway: A node designed to connect two entirely dissimilar networks operating on different protocols.
  • Bridge: Connects and filters traffic between two separate segments of the same local network into an aggregate network.

8. Essential Networking Terminology

  • Internet: A globally connected public network of millions of interconnected computer networks.
  • Intranet: A secure, private internal network accessible solely to members of a single organization.
  • Bandwidth: The maximum data handling capacity of a communication channel in a given timeframe (measured in bps, kbps, or mbps).
  • ISP (Internet Service Provider): A commercial organization providing Internet connectivity services to subscribers (e.g., Airtel, Jio, Vodafone).
  • Website & Web Page: A web page is an individual digital document hosted on the web; a website is a structured collection of interlinked web pages.
  • Home Page: The introductory or default main landing page of a website.
  • URL vs. IP Address:
    • URL (Uniform Resource Locator): The human-readable web address typed into a browser (e.g., https://www.example.com).
    • IP Address (Internet Protocol Address): The unique numerical identifier assigned to every device connected to a network.
  • Hyperlink & Hypertext: A hyperlink is a clickable reference link (text, button, or graphic) pointing to other resources. Text embedding these interactive links is known as Hypertext.

9. Quick Reference Summary

Concept Core Definition Key Association
Workstation vs. Server Client terminal vs. Central resource provider Client-Server Architecture
Transmission Media Guided (Cables) vs. Unguided (Wireless) Optical Fibre (Fastest wired) / Wi-Fi
Network Scale PAN < LAN < CAN < MAN < WAN Internet = Largest WAN
Hardware Intelligence Hub (Broadcasts to all) vs. Switch (Sends to target) Packet switching
Public vs. Private Internet (Open to world) vs. Intranet (Private organization) Security firewalls
Class 8 Revision Tip: Remember that in a Star Topology, failure of a single computer leaves the rest unaffected, but failure of the central switch stops the whole network. In contrast, in a Ring Topology, failure of any single computer breaks the whole circuit!
